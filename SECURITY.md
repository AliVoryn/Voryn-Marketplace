# Security Policy

## Scope

Security reports should cover protocol code, deployment scripts, configuration, access control, accounting, upgradeability, signature verification, and external integrations.

## Reporting

Do not disclose an unpatched vulnerability publicly. Provide a minimal reproduction, affected contract, impact, and suggested mitigation through a private security channel maintained by the repository owner.

## Operational note

The repository is not independently audited. Mainnet deployment requires an external security review and an explicit release approval process.
